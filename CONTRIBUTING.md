# Contributing to NaviDAM

At this stage, contributions are primarily coordinated through the OBSGESSION
and IMPACTS projects.

An open contribution process will be established as the project matures. In
the meantime, please open an issue or pull request to discuss a proposed
change.

NaviDAM is intended to be a collaborative open-source project. We welcome
feedback, documentation improvements, methodological contributions, and
technical fixes.

For an example of contribution guidance in a related project, see the
[LOST contribution guide](https://lost-stats.github.io/Contributing/Contributing.html).
